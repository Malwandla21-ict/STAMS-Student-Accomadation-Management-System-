# STAMS — Roofline (1c)

## Colours
- Harbour navy  #102A43 — primary, wordmark, dark backgrounds
- Electric iris #7B6CFF — roof accent, secondary icon background
- Chalk         #F5F3EC — light backgrounds, reversed marks

## Type
- Wordmark: Archivo ExtraBold (800), width 125% — outlined in all SVGs, no font needed
- Tagline / UI: Archivo SemiBold (600), uppercase, +0.16em tracking

## Files
- mark/ — symbol: colour, reversed (on navy), mono navy, mono white
- lockup/ — horizontal & stacked, with/without tagline, reversed; wordmark only; hi-res PNG
- icons/ — favicon.svg/.ico, favicon-16/32/48.png, apple-touch-icon.png, icon-192/512, maskable-512, site.webmanifest

## HTML head
```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#102A43">
```

## Usage
- Clear space: at least the roof height on all sides.
- Minimum size: mark 16px; horizontal lockup 96px wide; drop the tagline below 160px wide.
- Don't recolour, stretch, or add effects.
